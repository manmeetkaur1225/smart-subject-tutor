## Topic 1: Data Science vs Data Analytics

Data Science is an interdisciplinary field that combines statistics, mathematics, programming, and machine learning to extract meaningful insights from structured and unstructured data. It focuses on discovering hidden patterns, building predictive models, and solving complex real-world problems using data-driven techniques.

Data Analytics is the process of examining, cleaning, transforming, and interpreting existing data to identify trends, generate insights, and support better decision-making. Data Science focuses on prediction and discovery, whereas Data Analytics primarily focuses on understanding historical data and explaining what has happened and why.

## Topic 2: Data Preprocessing and the Four Major Steps

Data Preprocessing is a fundamental step in the Data Science lifecycle that converts raw, incomplete, and inconsistent data into a clean and suitable format for analysis and machine learning. Poor-quality data can lead to inaccurate predictions and unreliable results.

The four major steps of Data Preprocessing are:

1. Data Cleaning: Identifies and handles missing values, duplicate records, incorrect entries, and inconsistent data formats to improve data quality.

2. Data Integration: Combines data collected from multiple sources, such as databases, CSV files, APIs, and spreadsheets, into a unified dataset.

3. Data Transformation: Converts data into an appropriate format using techniques such as normalization, standardization, encoding categorical variables, and aggregation.

4. Data Reduction: Reduces the size and complexity of datasets while preserving important information using techniques such as feature selection, sampling, and dimensionality reduction.

## Topic 3: Exploratory Data Analysis (EDA), Statistics, and Data Visualization

Exploratory Data Analysis (EDA) is the process of investigating and summarizing datasets before applying machine learning algorithms. It helps identify patterns, relationships, trends, outliers, and unusual observations through statistical methods and visual representations.

EDA commonly uses the following statistical measures:

1. Mean: The arithmetic average of all numerical observations, calculated by dividing their total sum by the number of observations.

2. Median: The middle value of a dataset after arranging all observations in ascending or descending order.

3. Mode: The value that occurs most frequently in a dataset.

4. Standard Deviation: Measures how much individual data values differ or spread from the mean.

5. Correlation: Measures the strength and direction of the relationship between two numerical variables.

Data Visualization represents information graphically using charts and plots. Common techniques include bar charts, histograms, scatter plots, box plots, and heatmaps. Libraries such as Matplotlib and Seaborn in Python are widely used for effective data visualization.

## Topic 4: Machine Learning and Its Three Main Types

Machine Learning (ML) is a branch of Artificial Intelligence that enables computer systems to learn patterns from data and make predictions or decisions without being explicitly programmed for every task.

The three main types of Machine Learning are:

1. Supervised Learning: The model is trained using labelled data, where both input features and correct output values are provided. It is mainly used for Classification and Regression tasks. Examples include predicting house prices and detecting spam emails.

2. Unsupervised Learning: The model works with unlabelled data and discovers hidden patterns, structures, and relationships without predefined output labels. Common techniques include Clustering and Dimensionality Reduction. Examples include customer segmentation and grouping similar documents.

3. Reinforcement Learning: An intelligent agent learns by interacting with an environment and receiving rewards or penalties for its actions. Its objective is to maximize the total cumulative reward. Examples include robotics, game-playing systems, and autonomous navigation.
